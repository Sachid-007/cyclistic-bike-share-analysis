# Cyclistic Bike-Share Analysis

## Business Objective
Analyze how annual members and casual riders use Cyclistic bikes differently
and provide data-driven recommendations to increase annual memberships.

## Tools Used
- SQL (BigQuery)
- Tableau Public

## Dataset
12 months of Cyclistic trip data (Dec 2024 – Nov 2025), ~5.3 million rides.

## Process
1. Ingested and combined monthly trip data
2. Performed data quality checks
3. Cleaned and validated raw data
4. Created analysis-ready datasets
5. Built interactive Tableau visualizations
6. Generated insights and recommendations

## Key Insights
- Casual riders take longer trips and ride mostly on weekends
- Members ride more frequently on weekdays
- Bike usage peaks in summer, with August as the highest month
- Electric bikes are the most used by both user groups

## Recommendations
- Launch summer-focused membership campaigns
- Introduce family membership plans
- Offer weekend-based conversion promotions
- Use usage-based nudges to convert frequent casual riders
